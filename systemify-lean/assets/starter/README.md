# Site and style guide

```bash
npm install
npm run dev
```

Open http://localhost:8080 and http://localhost:8080/style-guide/.

- `tokens/tokens.json`: every value (colour, type, space, breakpoints). Edit here.
- `src/css/`: reset, base (elements and voices), compositions (layout), blocks (components), utilities.
- `src/_includes/components/`: the components. `src/_data/components.json` describes them.
- `docs/audit.md`: what the original site measured. `docs/decisions.md`: why. `GAPS.md`: what is open.
