# Typography

**One text style per role**, named **category-size-modifier**, the scheme most large
design systems use:

| Category | Sizes | Modifiers |
| --- | --- | --- |
| `display` | lg | |
| `heading` | lg, md, sm | |
| `body` | lg, md, sm | `-strong` (bold), `-italic` |
| `label` | md, sm | `-strong` (medium) |

So `heading-lg` is the section title , `body-md-strong` the bold meta line.
New sizes slot in without renaming (`heading-xl`, `body-xs`).

`heading-lg` is one style, not "heading desktop" and "heading mobile": its size
changes with the breakpoint inside the token: size, line height and letter spacing
each have three modes (Mobile, Tablet, Desktop).

In code, a component applies the whole style in one line:

```css
.ds-heading { font: var(--ds-text-heading-lg); letter-spacing: var(--ds-text-heading-lg-letter-spacing); }
```

and the two generated media queries in `tokens.css` switch the sizes:

```css
@media (min-width: 50em) { :root { --ds-typography-heading-lg-font-size: var(--ds-font-size-40); } }
```

The system font stack until the audit names the real typeface. Self-host it (no request to Google) in the weights the source uses.
All sizes measured on the live site (see `docs/audit.md`); rem, so they grow with
the reader's font settings. Switch the viewport to see the samples change.
