# Colour

Two tiers, as in every other foundation:

| Tier | What it is | Example | Who uses it |
| --- | --- | --- | --- |
| **Primitive** | The raw palette, named by hue and step | `--ds-color-neutral-800` | Only the semantic tier |
| **Semantic** | What a colour is **for**; each one points at a primitive | `--ds-color-text-strong` → neutral-800 | Components |

Components only ever use semantic colours (the validator checks it). To change
the heading colour everywhere, point `text.strong` at another primitive in
`tokens.json`.

One light theme, as on the source.
